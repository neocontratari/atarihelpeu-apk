AtariHelp.eu EMU-10 BUILD2BB_CLOAD_CSAVE_WAV_SAVE_FIX

Navazuje na BUILD2BA.

Zmeny:
1) START + OPTION
- Horni tlacitko START + OPTION drzi START i OPTION uz pri cold startu.
- Neni to SELF TEST.
- Pouziti: kazetovy/turbo start jako na realnem Atari.

2) VLOZIT KAZETU / PLAY
- PLAY uz nikdy neotevira Downloads.
- Klepnuti na telo/okno XC12 kazety = VLOZIT KAZETU.
- Pokud kazeta stoji a uz je vlozena, nove klepnuti na telo kazety rovnou otevre Downloads a umozni vymenit WAV/CAS/MP3 bez loveni druheho STOP.

3) CSAVE / SAVE "C:"
- RECORD zapne CSAVE ARM.
- Po prikazu CSAVE nebo SAVE "C:" a po STOP/EJECT emulator vyhodnoti realne zachycene SEROUT bajty.
- Pokud prisla skutecna data, ulozi automaticky CAS i WAV do Downloads/AtariHelp:
  AtariHelp_CSAVE_BASIC_YYYYMMDD_HHMMSS.cas
  AtariHelp_CSAVE_BASIC_YYYYMMDD_HHMMSS.wav
  nebo TBXL podle rezimu.
- Pokud neprisla realna data, nic se neulozi a log rekne NE. Zadny fake.

4) WAV CLOAD pokus
- WAV dekoder je ted opatrnejsi.
- Pokud detekce standardniho 600 baud FSK vyjde s nizkou duverou, data se neposlou do POKEY SERIN, aby nevznikal BOOT ERROR z nahodnych/garbage bajtu.
- WAV se stale prehrava jako skutecna paska se zvukem, counterem a pretacenim.
- Turgen/turbo WAV zustava slozitejsi dalsi faze.

5) Test:
A) CSAVE BASIC:
- POWER BASIC
- napis kratky program
- RECORD
- CSAVE
- pockej
- STOP/EJECT
- v logu hledej CSAVE VYSLEDEK: ANO a oba soubory v Downloads/AtariHelp.

B) Vymena kazety:
- vloz WAV/CAS
- PLAY
- STOP/EJECT
- klepni na telo kazety
- ma se otevrit Downloads pro novou kazetu.

KODY JSOU STEJNE.
Jadro emulatoru, ROM logika a BASIC/Altirra testovaci kody nebyly meneny. Zmeny jsou kazetak/UI/ukladani WAV+CAS a ochrana pred nizkoduverovym WAV decode.
