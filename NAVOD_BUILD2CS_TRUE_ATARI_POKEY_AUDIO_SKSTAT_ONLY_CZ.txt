ATARIHELP.EU EMU-10 - BUILD2CS_TRUE_ATARI_POKEY_AUDIO_SKSTAT_ONLY
=================================================================

DUVOD BUILD2CS
--------------
René spravne nasel hlavni problem: kazeta a zvuk nesmi mit dve cesty a nesmi se po leaderu lepit hotove SERIN bajty mimo zvuk.
BUILD2CS proto dela tvrdý rez:

- zaklad je BUILD2BZ/BY golden
- BUILD2CK/CL/CM/CN/CO/CP/CQ/CR nejsou zaklad
- TXT line queue zustava z BUILD2BZ
- joystick/scroll/focus zustava z BUILD2BY/BZ
- KODY JSOU STEJNE

CO JE ZMENENO
-------------
1) Kazeta nema Android/HTML Audio.
   PLAY uz nepusti druhy zvukovy casovac.

2) LAST CSAVE CLOAD uz nejde pres hotovou SERIN frontu.
   Cely skutecne zachyceny POKEY SEROUT stream z CSAVE jde jako 600 baud FSK bitstream:

   POKEY SEROUT zachyt -> 600 baud FSK -> SKSTAT bit4 / DATAIN -> ROM/BASIC CLOAD

3) Slyšitelny kazetovy monitor jde ze stejne core cesty jako SKSTAT bit4.
   Neexistuji dva zvuky.

4) Klavesovy klik zustava jen z ROM/GTIA speaker zapisu $D01F.
   Herni zvuk zustava jen z POKEY registru AUDC/AUDF/AUDCTL.

5) Zadny RAM inject.
   Zadny fake READY.
   Zadna hotova BASIC data do RAM.
   Zadna paralelni HTML Audio kazeta.

PISMO/ZVUK
----------
Pismo READY/Atari font neni zapomenuto. Nebylo meneno v BUILD2CS, protoze tento build resi duverovy problem POKEY/kazety.
Dalsi samostatna faze po stabilizaci kazety:
- font/CHBASE/Atari charset pro READY
- presnejsi POKEY audio/poly/noise podle realneho 130XE

TEST PLAN
---------
1) Nahraj overlay BUILD2CS pres GitHub Desktop.
2) Spust appku v NOX/Androidu.
3) POWER -> BASIC READY.
4) BASIC TXT vloz stejny testovaci program jako predtim.
5) Nech TXT dopsat, musi byt QUEUE COMPLETE.
6) Pro CSAVE:
   - pouzij RECORD / CSAVE workflow jako driv
   - po CSAVE se musi ulozit CAS+WAV a zustat LAST CSAVE cache
7) Dej CLOAD test z posledni CSAVE.
8) PLAY nesmi pustit Android/HTML zvuk.
   Slyset musi byt jen jedna kazetova core cesta.
