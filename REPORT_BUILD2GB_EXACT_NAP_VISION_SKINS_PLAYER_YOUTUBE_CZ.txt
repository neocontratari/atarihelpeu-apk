TEST PLAN
1. Spust aplikaci.
   Ocekavani: nova presna uvodni obrazovka N&P VISION Command Center.

2. Klikni EMULATOR.
   Ocekavani: otevre se existujici skutecny Atari emulator z emu/index.html.

3. Vrat se a klikni PREHRAVAC.
   Ocekavani: otevre se presna obrazovka cassette playeru.

4. V prehravaci klikni MY PLAYLISTS / PLAYLISTS / LIBRARY.
   Ocekavani: otevre se playlist panel.

5. Pridej MP3 nebo WAV.
   Ocekavani: soubor se zaradi do playlistu.

6. PLAY / PAUSE / STOP / REWIND / FAST FWD.
   Ocekavani: ovlada prehravani vybraneho souboru.

7. Klikni YOUTUBE v prehravaci.
   Ocekavani: musi otevrit https://www.youtube.com/ a nesmi otevrit emulator.

8. Klikni ATARIHELP.EU na uvodu.
   Ocekavani: otevre https://atarihelp.eu/

9. Otestuj EQ / BALANCE / BASS / TREBLE / VOLUME.
   Ocekavani: meni zvuk prehravace pres WebAudio. Grafika je skin, ovladace se vizualne netoci 1:1.
