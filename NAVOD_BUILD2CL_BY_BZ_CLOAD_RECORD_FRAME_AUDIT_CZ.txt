ATARIHELP.EU EMU-10 BUILD2CL_BY_BZ_CLOAD_RECORD_FRAME_AUDIT
================================================================

KODY JSOU STEJNE.
Jadro / ROM / BASIC testovaci kody se nemeni.
BUILD2CL vychazi ze spravneho zakladu BUILD2BZ_BY_GOLDEN_TXT_LINE_QUEUE_FIX.
TXT line queue z BUILD2BZ NEMENEN.
Joystick/scroll/focus z BUILD2BY/BZ NEMENEN.
BUILD2CK se NEPOUZIVA jako zaklad; CK byl jen dukaz, ze SKRES hold nepomohl.

CO JE ZMENENO:
- CLOAD cesta pro vlastni CSAVE uz nebere cely zachyceny SEROUT stream jako jeden dlouhy proud dat.
- BUILD2CL rozpozna standardni Atari cassette recordy po 132 B:
  2x $55 marker + control byte + 128 dat + checksum.
- Do OS/POKEY SERIN se ted posila jen control byte + 128 dat z kazdeho recordu.
- Markery $55 a checksumy se necpou jako BASIC data, protoze BUILD2CK log ukazal zasek presne na checksumu prvniho 132B recordu.
- Mezi recordy je vlozena kratka kazetova mezera, aby OS mohl dokoncit blok a prejit na dalsi.
- Pridany audit logy:
  CLOAD RECORD BUILD2CL: rozpoznano X standardnich 132B recordu...
  CLOAD RECORD BUILD2CL: record N START...
  CLOAD RECORD BUILD2CL: record N DATA END...
- Zadny RAM inject, zadne fake CLOAD, zadne cteni BASIC programu z RAM.

PISMO A ZVUK:
- Nezapomenuto.
- V BUILD2CL zatim ZAMERNE NEMENENO, aby se nerozbil BZ golden zaklad.
- Dalsi samostatna faze po CLOAD: presnejsi Atari charset/CHBASE render READY a vernejsi XC12/FSK monitor zvuk.

PROC TENTO BUILD:
- Posledni log BUILD2CK padal kolem hranice prvniho standardniho recordu:
  SERIN predano 128/526 B
  pak drzen byte $A8
  PC=$ED4F, IRQEN=$C0, IRQST=$CF
- 528 B zachyceneho CSAVE = presne 4 x 132 B standardni cassette record.
- Atari kazetovy record ma 132 B, ale BASIC/CLOAD datova cast neni cela 132B jako programova data.

TESTOVACI PLAN PRESNE:
1) Nainstaluj BUILD2CL overlay pres GitHub Desktop jako obvykle.
2) Spust aplikaci v NOXu.
3) POWER -> pockat na READY.
4) BASIC/TBXL TXT.
5) Vloz tento stredni test:

10 PRINT "ATARIHELP BZ"
20 PRINT "TXT+CSAVE+CLOAD"
30 S=0
40 FOR I=1 TO 20
50 S=S+I
60 PRINT I,S
70 NEXT I
80 IF S=210 THEN PRINT "SUM OK"
90 IF S<>210 THEN PRINT "SUM BAD"
100 FOR A=1 TO 8
110 PRINT "A=";A;" AA=";A*A
120 NEXT A
130 PRINT "KONEC OK"
140 END

6) Dej VLOZIT + RUN.
   Spravne: program dobehne a vypise SUM OK a KONEC OK.
7) Dej CSAVE.
   Cekej na log: CSAVE VYSLEDEK: ANO.
   Spravne: zachyt kolem 528 B nebo podobne podle programu.
8) Dej LAST CSAVE / SAVE.
   Spravne: vlozi se posledni WAV/CAS z pameti emulatoru.
9) Napis NEW a dej RETURN.
10) Napis LIST a dej RETURN.
    Spravne: program je prazdny / nic duleziteho se nelistuje.
11) Napis CLOAD a dej RETURN.
12) Dej PLAY.
13) Po dokonceni zkus LIST a RUN.

OCEKAVANY SPRAVNY VYSLEDEK:
- V logu musi byt:
  CLOAD RECORD BUILD2CL: rozpoznano 4 standardnich 132B kazetovych recordu...
  CLOAD RECORD BUILD2CL: record 1 START...
  CLOAD RECORD BUILD2CL: record 1 DATA END...
  potom record 2 START / DATA END atd.
- Na Atari obrazovce po CLOAD nesmi byt ERROR 138.
- LIST musi ukazat program.
- RUN musi vypsat SUM OK a KONEC OK.

KDYZ TO SELZE:
- Posli cely LOG / CHYBA.
- Hlavne potrebuju cast od:
  CLOAD RECORD BUILD2CL: rozpoznano...
  pres record START/DATA END
  az po ERROR 138 nebo READY.
- Napis, jestli se chyba zastavila znovu na $A8, nebo na jinem byte.
