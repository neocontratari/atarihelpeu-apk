Co je nove:
1) BUILD2IE true 640 text canvas
- Cisty VBXE TEXT-only XDL uz nejde predem do 384px Atari framebufferu.
- Pro Textmode Test se vytvori 640x240 prezentacni canvas.
- Text se kresli nativne 80 znaku x 8 pixelu = 640 px.
- Cilem je ostrejsi Textmode bez ztraty pul-pixelovych tahu.

2) Safe omezeni
- Pokud XDL obsahuje grafiku SR/LR/HR, zustava puvodni bezpecna graficka cesta.
- W3D/Heartlight grafika by se timto buildem nemela menit.
- Smisene TEXT+GRAPH XDL zustavaji low-res fallback, aby se nerozbilo W3D/HL.
