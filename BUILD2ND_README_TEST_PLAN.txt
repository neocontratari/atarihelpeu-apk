DUVOD:
Predchozi lrusso cesta neprinesla viditelny obraz. BUILD2ND ji pro test vypina a jde primo na ClownMDEmu web frontend, ktery je hotovy frontend k ClownMDEmu core.

TEST:
1) Rozbal ZIP pres koren projektu.
2) Spust APK.
3) Otevri SEGA modul.
4) Klikni HRY nebo SBIRKA nebo CARTRIDGE SLOT.
5) Ma se otevrit oficialni ClownMDEmu web frontend.
6) V jeho vlastnim UI vyber ROM (.gen/.bin/.md).
7) Ocekavani: realna grafika a zvuk z ClownMDEmu web frontend, ne moje fake grafika.
8) Kdyz se stranka neotevre nebo upload ROM nefunguje, posli screenshot.

POCTIVE:
- Tohle jeste neni offline native integrace do naseho skinu.
- Je to prime overeni ClownMDEmu cesty v Android WebView/Nox: grafika/zvuk ano/ne.
- Pokud to pobězi, dalsi krok je lokalni/offline integrace nebo native/JNI.
