KODY JSOU ZMENENE

Co bylo fyzicky udelano:
- Overlay je znovu slozeny jako jedna cista vetev.
- Z puvodniho FIX358 je ponechano pouze hlavni emulatorove jadro.
- Vsechny pozdejsi prilepene overlay script bloky za jadrem byly odstraneny.
- Viditelne stare UI panely byly nahrazeny cistym minimalnim panelem FIX362.
- NaPatari130xe.rom je vlozena natvrdo do HTML jako base64 a take prilozena v assets pro kontrolu.
- TBXL XEX je vlozen natvrdo do HTML jako base64 a take prilozena kopie v assets.
- Pridana jedna ROM/MMU brana: C000-CFFF a D800-FFFF cte 16KB OS ROM pouze kdyz PORTB bit0=1; pri bit0=0 je RAM pod OS ROM.
- BASIC okno A000-BFFF se ridi PORTB bit1; pro TBXL start je PORTB=$FF = OS ON / BASIC OFF.
- Start TBXL provadi XEX segment load, relokaci do RAM pod ROM a skok na $6179.
