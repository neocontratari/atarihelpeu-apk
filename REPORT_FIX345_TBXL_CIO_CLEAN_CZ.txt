AtariHelp.eu EMU-09 - FIX345_TBXL_CIO_CLEAN

KODY JSOU ZMENENE.
Tohle je dopředný overlay na FIX330.

Co je opraveno:
- Přidán čistý FIX345 script na konec HTML
- XEX loader používá fetch() + parseXex345() - čte segmenty přímo z assets
- Segmenty se zapíší do emulované RAM ($4980-$9B00 + RUNAD $02E0-$02E1)
- Skok na RUNAD $6132 pod zapnutým Atari OS
- CIO vstupní cesta: hook na CIOV $E456 - při GET z E: dodá CH $02FC
- CH/KBCODE/SKSTAT inicializovány na $FF před startem

Zachováno z FIX330:
- POWER XL/XE BASIC funguje beze změny
- TXT/BAS vkládání přes KGETCH/ATASCII
- Mobilní Atari klávesnice
- Warm reset

Test postup:
1) Otevři appku - musí být FIX345_TBXL_CIO_CLEAN v titulku
2) Stiskni POWER XL/XE BASIC - ověř že BASIC READY funguje
3) Stiskni SPUSTIT TBXL 1.5 FIX345
4) Po READY zkus napsat A + RETURN
5) Zkus PRINT 2+2 + RETURN - musí odpovědět 4
6) Pokud READY cyklí nebo klávesnice nepíše - ulož FIX345 LOG

Zakazy:
NO_FAKE_READY=YES
NO_FAKE_LOAD=YES
NO_FAKE_SELF_TEST=YES
NO_RAM_PROGRAM_INJECT=YES
NO_SCREEN_PAINT=YES

SHA256 souboru turbo-basic-xl-1.5.xex se nemění.
