AtariHelp.eu EMU-10 BUILD2AD_LINKS_AUDIOSTOP_CASSETTE_ANIM
=====================================================

NAVAZUJE NA:
- BUILD2AC_NET_AUTORUN_DOCK_FIX

HLAVNI ZMENY:
1) UVODNI OBRAZOVKA
- SETTINGS vede na: https://atarihelp.eu/
- SYSTEM vede na: https://atarihelp.eu/?page_id=786
- prostredni ikona EMULATOR je mirne srovnana, aby popis nebyl rozjety.

2) EMULATOR / WAV-MP3-CAS AUDIO MONITOR
- Kdyz se spusti WAV/MP3/CAS pres tlacitko WAV/CAS, fyzicke PAUSE na kazetaku audio okamzite zastavi.
- Fyzicke STOP/EJECT na kazetaku audio okamzite zastavi.
- Pri zastaveni se zrusi prehravani, vynuluje pozice, zrusi se object URL a vypne animace kotoucu.
- Stale plati: neni to fake CLOAD inject do RAM. Kazeta je pripravena pro budouci ciste CLOAD/CSAVE.

3) KAZETAK ANIMACE
- Kazetova tlacitka maji silnejsi animaci stisku dolu.
- Pri zmacknuti je videt tmavy stiskovy prekryv a tlacitko pusobi jako v poloze dole.

4) SPODNI SERVISNI TLACITKA
- Servisni tlacitka pod kazetakem jsou tmava / fyzicka jako tlacitka pod monitorem.
- NET HRY zustava pro web AtariHelp.eu hry.
- XEX MOBIL zustava lokalni vyber z mobilu.
- ATR DISK, TURBO BASIC, BASIC/TBXL TXT, WAV/CAS, LOG/CHYBA a MENU zustavaji.

TESTY:
1. Uvodni obrazovka -> SETTINGS musi otevrit https://atarihelp.eu/
2. Uvodni obrazovka -> SYSTEM musi otevrit https://atarihelp.eu/?page_id=786
3. Emulator -> WAV/CAS -> vyber WAV nebo MP3 -> po spusteni stiskni PAUSE: audio se musi hned zastavit.
4. Znovu WAV/CAS -> vyber WAV nebo MP3 -> po spusteni stiskni STOP/EJECT: audio se musi hned zastavit.
5. Zmackni fyzicka tlacitka kazetaku: musi byt videt hlubsi stisk dolu.
6. NET HRY -> klik na hru z webu: nesmi po navratu probehnout POWER BASIC reset.

KODY JSOU STEJNE.
BASIC/Altirra testovaci kody se nemenily.
Jadro emulatoru je beze zmen, zmeny jsou UI/linky/audio stop/animace.
