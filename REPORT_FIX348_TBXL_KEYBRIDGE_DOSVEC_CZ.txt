AtariHelp.eu EMU-09 - FIX348_TBXL_KEYBRIDGE_DOSVEC

KODY JSOU ZMENENE.

POTVRZENO testem Rene (2026-06-09 22:47, Nox):
- TBXL titulek "TURBO-BASIC XL 1.5 (c) 1985 Frank Ostrowski" se vykreslil!
- MEM_6132: A0 00 84 32 84 34 A9 49 = skutečný TBXL kód v RAM.
- XEX load + RUNAD $6132 funguje. Poprvé od FIX338.

Zbývající problémy z testu:
1. Seklo se po titulku: PC=$F5EC = OS čeká na klávesu, CH zůstává $FF.
   Mobilní klávesnice nedoručuje do TBXL.
2. Špatné barvy titulku (řešíme později, až bude vstup).
3. Warm reset po TBXL = rozsypaný obraz (DOSVEC mířil do prázdna).

Oprava FIX348:
1. KLÁVESNICOVÝ MOST: stisk tlačítka mobilní klávesnice zapíše
   XL OS keyboard code do CH $02FC + KBCODE $D209 + SKSTAT pulse.
   Převod ATASCII->keycode jde přes existující ROM tabulku jádra
   (realOsKeycodeForAtasciiFix172) - žádná nová mapa.
   Most je aktivní JEN v TBXL módu. POWER BASIC ho vypne
   a vrátí původní chování (BASIC/TXT/KGETCH se nemění).
2. DOSVEC $000A = $6132 + COLDST=0 po TBXL loadu.
   Warm reset (RESET) projde OS warm startem a vrátí se do TBXL.

Test postup:
1) POWER XL/XE BASIC - ověř základ (nesmí být rozbitý)
2) SPUSTIT TBXL 1.5 FIX348
3) Počkej na TBXL titulek
4) Stiskni A na mobilní klávesnici - log musí ukázat "KEY A -> ATASCII $41"
   a na obrazovce se musí objevit A
5) RETURN -> ERROR (správně! TBXL čte vstup)
6) Napiš: PRINT 2+2 + RETURN -> musí vypsat 4
7) Napiš: CLS + RETURN -> smaže obrazovku (důkaz Turbo Basicu)
8) TEPLÝ RESET -> musí se vrátit do TBXL READY, ne do nesmyslů
9) Ulož log (tlačítko FIX345 LOG) a pošli

Pravda: barvy titulku zatím neřeším - GTIA/palette dluh přijde
po potvrzení vstupu. Jedna vrstva po druhé.
