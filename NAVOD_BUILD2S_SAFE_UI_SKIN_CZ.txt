AtariHelp.eu EMU-10 BUILD2S SAFE UI SKIN
========================================

Partaku, toto je bezpečný UI overlay na BUILD2R_oprava_PMgrafiky.

CO JE ZMENENE
-------------
1) app/src/main/assets/index.html
   - nová úvodní obrazovka N&P VISION ve stylu černo/zlato CRT + kazeta + MAIN MENU.
   - odkazy zůstávají funkční: EMULATOR / TAPE LOADER otevírá emu/index.html, ostatní odkazy vedou na atarihelp.eu.

2) app/src/main/assets/emu/index.html
   - nový vizuální skin podle návrhů: CRT nahoře, POWER BASIC, POWER+OPTION SELF TEST,
     přepínač KEYBOARD/JOYSTICK, značka ATARI 130XE, horní funkční řada HELP START SELECT OPTION RESET,
     originální 130XE klávesnice a XC12 kazetová část.
   - zachované původní ID prvky, aby se nerozbily JavaScript vazby:
     scr, led, btnPower, btnSelfTest, btnReset, btnBreak, btnHelp, btnStart, btnSelect,
     btnOption, btnXex, btnAtr, btnTbxl, btnJoy, btnTxt, btnProgNew, chkOpt, filePick,
     osk, joy, joyPad, joyKnob, joyFire, log a overlaye.
   - klávesnice přepsaná na uzamčenou mapu Atari 130XE:
     Row 1: Esc, !/1, "/2, #/3, $/4, %/5, &/6, '/7, @/8, (/9, )/0, Clear/<, Insert/>, Delete/Bk Sp, Break
     Row 2: Clr/Set Tab, Q W E R T Y U I O P, ↑/-, ↓/=, Return
     Row 3: Control, A S D F G H J K L, :/;, ←/+, →/*, Caps
     Row 4: Shift, Z X C V B N M, [/,, ]/., ?//, Shift, Fuji/INVERSE
     Row 5: Space

CO NENI ZMENENE
---------------
- Emulatorové jádro v JS z BUILD2R není přepisované.
- XEX/ATR/TBXL loader logika zůstává.
- POKEY audio logika zůstává.
- PMG oprava z BUILD2R zůstává.
- Android Java WebView obsluha, file chooser, download a AHSAVE zůstávají.
- Žádný fake READY, žádný paint místo emulátoru, žádný RAM inject.

KODY JSOU STEJNE
----------------
- BASIC/Altirra testovací kódy nejsou měněné.
- Tento balík je UI skin, ne změna testovacích programů.

JAK NAKOPIROVAT
---------------
1) Rozbal ZIP.
2) Překopíruj složku app přes stávající projekt v GitHub Desktop / pracovním adresáři.
3) Potvrď přepsání souborů.
4) Buildni APK stejně jako BUILD2R.

TEST PLAN
---------
1) Spustit aplikaci: má najet nová úvodní N&P VISION obrazovka.
2) Kliknout EMULATOR / TAPE LOADER.
3) POWER BASIC: ověřit, že se stále spouští emulátor, ne statický obrázek.
4) POWER + OPTION SELF TEST: ověřit, že funguje původní Self Test cesta.
5) Přepnout JOYSTICK: musí se schovat klávesnice a ukázat palcový joystick + FIRE.
6) Přepnout zpět KLAVESNICE: musí se vrátit klávesnice.
7) NAHRAJ XEX / ATR / TBXL / VLOZIT TXT: ověřit, že tlačítka reagují.
8) ULOZIT LOG: ověřit, že AHSAVE pořád funguje.

POZOR
-----
Je to bezpečný vizuální skin. Když se objeví problém, hledat nejdřív v CSS/rozložení,
ne v jádru emulátoru. Funkční ID prvky jsou záměrně zachované.
