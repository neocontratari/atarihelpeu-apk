# N&P VISION – KARTY HLAVNÍHO MENU (B311, B314 česky + anglicky)
#
# Každý řádek = jedna velká karta v menu. Pořadí řádků = pořadí karet zleva doprava.
# Novou mašinu nebo sekci přidáš tak, že dáš obrázek do assets/menu/ a připíšeš řádek.
# Menu (posouvání, tečky, dotyk) se přizpůsobí samo, v kódu se nic nemění.
#
#  id | NÁZEV | podtitul | popis | obrázek | cíl | barva | zámek | efekt | tlačítko | NAME | subtitle | description | button
#
#  id        krátké jméno bez mezer (log, zámky)
#  NÁZEV     velký nápis na kartě
#  podtitul  malý nápis pod názvem
#  popis     věta pod kartami
#  obrázek   obrázek karty (png nebo jpg, nejlépe 600 x 800) v assets, např. menu/karta_atari.jpg
#  cíl       stránka v aplikaci (emu_sega/index.html), web (https://...), nebo akce:nastaveni
#            (otevře OPTIONS) či akce:intro (pustí úvodní film)
#  barva     barva karty #RRGGBB (záře, tečky, pozadí)
#  zámek     sega / ps1 = otevře se postupem hráče; prázdné = vždy otevřená
#  efekt     živý obrázek kreslený v C++ (3d:atari, 3d:nap16, 3d:nap32, fx:kazeta,
#            fx:dzubox, fx:web, fx:help); prázdné = jen obrázek
#  tlačítko  text tlačítka pod kartami (prázdné = OTEVŘÍT)
#
#  B314 – ANGLICKY (OPTIONS → JAZYK · LANGUAGE → ENGLISH): poslední 4 sloupce
#  NAME, subtitle, description, button = totéž anglicky. Prázdný anglický sloupec = český text
#  (tlačítko: OPEN).
#
