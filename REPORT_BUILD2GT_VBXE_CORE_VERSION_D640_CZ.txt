CO UKAZAL TVUJ TEST BUILD2GS:
- Popeye se nacte jako VBXE XEX s 625 zaznamy.
- Program dojde az na vlastni hlasku:
  No VBXE found or no FX core
- Trace ukazal opakovane:
  VBXE TRACE R $D640 = $FF PC=$8C63
- To znamena, ze Popeye v teto fazi testuje registr $D640 / Dx40.

CO JE OPRAVENO V BUILD2GT:
- $D640 / Dx40 pri cteni uz vraci CORE_VERSION = $10.
- To neni fake bypass, je to primo dokumentovana hodnota registru:
  Dx40 write = VIDEO_CONTROL, read = CORE_VERSION (= $10).
- Ostatni registry se zatim nefakují jako hotovy cip:
  $D64A = COLDETECT default 0
  $D650 = BLT_COLLISION_CODE default 0
  $D653 = BLITTER_BUSY idle 0
  $D654 = IRQ_STATUS no IRQ 0
  ostatni zatim $FF + trace

PROC:
Ted chceme zjistit, jestli Popeye projde pres prvni detekci.
Pokud ano, dalsi log ukaze dalsi realne registry, ktere hra potrebuje.
