FIX119 NO ROM REQUIRED CORE

- Externí Atari OS ROM ani BASIC ROM není vyžadovaná.
- Viditelné ROM akce jsou přepsané na vysvětlení: nic nenahrávej.
- Mini OS/CIO shim zůstává povinný interní fallback.
- Donkey / Cobra / Arkanoid reference zůstávají chráněné.
- Cíl další práce: reálnější interní OS/CIO/VBI chování, ne ruční ROM workflow pro testera.
