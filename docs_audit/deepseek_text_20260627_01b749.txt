2. ROZBOR CHYBY – NIGHT DRIVER (pruh na konci auta)
--------------------------------------------------------------------------------

PŘÍZNAK:
Hra běží, grafika je jinak v pořádku, ale na autě chybí přední pruh (část karoserie,
světla nebo nárazník). Zbytek auta je vykreslen správně.

PŘÍMÁ PŘÍČINA Z LOGU:
Emulátor používá "SR Stripe Filter" (BUILD2LC), který aktivně vyhledává vodorovné
pruhy (stripes) a považuje je za artefakty – typicky je přebarví nebo retušuje
pomocí okolních pixelů.

Konkrétní záznam v logu:
-------------------------------------------
VBXE SR STRIPE FILTER BUILD2LC: izolovana SR artefakt-radka y=233 yy=0 opaque=256
run=256 same=256 neigh=128; bez screen-paintu.
-------------------------------------------

Tento filtr omylem označí přední vodorovnou část auta za "rušivý pruh" a odstraní ji.
Protože se nejedná o celé auto, ale jen o souvislý vodorovný pruh (typický pro
přední nárazník nebo kapotu), filtr ho vyretušuje a zbytek auta nechá.

3. ROZBOR CHYBY – POPEYE (schodiště / plochy chybí)
--------------------------------------------------------------------------------

PŘÍZNAK:
Hra se načte, postavy a některé overlay vrstvy jsou vidět, ale chybí schodiště
a vodorovné plochy, po kterých Popeye chodí. Místo nich je prázdné pozadí
(typicky černá nebo průhledná plocha).

PŘÍMÁ PŘÍČINA Z LOGU:
Emulátor obsahuje ochranný mechanismus "Tile Surface Underlay" (BUILD2JU), který
blokuje vykreslení dlaždicových povrchů, pokud nejsou vyhodnoceny jako "silný
kandidát". Důvodem je předchozí nestabilita u Popeye (v logu je přímo zmínka
"kvuli Popeye caji").

Konkrétní záznamy v logu:
-------------------------------------------
VBXE VRAM PROBE SKIP BUILD2JU: pred-XDL diagnostiku nekreslim pres aktivni
Atari/ANTIC obraz. Vyjimka je jen realny tile-surface underlay do COLBK pozadi;
kdyz neni silny kandidat, blokuje se to kvuli Popeye caji.
---
VBXE TILE SURFACE BUILD2JU: realne BCB tile blity base=$04000 step=256
bbox=52,56-203,243 blocks=64 bytes=8192; zatim jen kandidat pro pre-XDL underlay,
ne hack podle hry.
-------------------------------------------

Schody v Popeye jsou přesně ten typ pozadí, který se kreslí jako tile surface
pomocí blitteru. Protože je tento underlay zablokovaný (není vyhodnocen jako
"silný"), schody se nevykreslí – zůstane prázdná plocha.

struct RenderContext {
    string loadedFileName;      // název načteného souboru (malá písmena)
    uint32 fileCRC;            // volitelně – pro identifikaci podle CRC

struct EmulatorConfig {

// ================================================================
//  IDENTIFIKACE HER (podle názvu nebo CRC)
// ================================================================

void identifyGame(RenderContext &ctx) {
    string name = ctx.loadedFileName;
    // převod na malá písmena pro jistotu
    transform(name.begin(), name.end(), name.begin(), ::tolower);
    
    ctx.isNightDriver = (name.find("nightdriver") != string::npos) ||
                        (name.find("night_driver") != string::npos) ||
                        (ctx.fileCRC == 0x12345678); // doplňte skutečný CRC Night Driver
    
    ctx.isPopeye = (name.find("popeye") != string::npos) ||
                   (ctx.fileCRC == 0x87654321);       // doplňte skutečný CRC Popeye
}

// ================================================================
//  HLAVNÍ RENDEROVACÍ CYKLUS (KAŽDÝ SNÍMEK)
// ================================================================

void renderFrame() {
    // Získání aktuálního kontextu a konfigurace
    RenderContext ctx = getCurrentRenderContext();
    EmulatorConfig cfg = getCurrentConfig();
    
    // Předpočítání identifikace her (stačí jednou po načtení souboru)
    identifyGame(ctx);
    
    // --- KROK 1: ZPRACOVÁNÍ SR / HR OVERLAY (VBXE) ---
    if (vbxeEnabled) {
        
        // 1a) Pro každý SR scanline rozhodneme o použití Stripe Filter
        for each scanline in srScanlines {
            // Naplníme parametry do kontextu
            ctx.currentScanlineY = scanline.y;
            ctx.stripeOpaque = scanline.opaque;
            ctx.stripeRun = scanline.run;
            ctx.stripeSame = scanline.same;
            ctx.stripeNeigh = scanline.neigh;
            
            if (shouldApplyStripeFilter(ctx, cfg)) {
                applyStripeFilter(scanline.y, scanline.opaque, 
                                  scanline.run, scanline.same, scanline.neigh);
            }
            // Jinak scanline necháme beze změny – pruh zůstane zachován
        }
        
        // 1b) Zpracování tile surface kandidátů (underlay)
        List<TileCandidate> candidates = detectTileCandidates(); // vaše detekce
        for each candidate in candidates {
            if (shouldRenderTileUnderlay(candidate, ctx, cfg)) {
                renderTileUnderlay(candidate);
            }
        }
    }
    
    // --- KROK 2: KRESLENÍ ANTIC/GTIA POZADÍ A PMG ---
    renderAnticAndPMG();
    
    // --- KROK 3: FINÁLNÍ KOMPOZICE ---
    composeFinalImage();
}

// ================================================================
//  JAK NASTAVIT KONFIGURACI PRO TYTO DVĚ HRY (PŘÍKLAD)

void setupGameSpecificConfig(EmulatorConfig &cfg, RenderContext &ctx) {
    // Výchozí hodnoty
    cfg.srStripeFilterEnabled = true;
    cfg.stripeNeighborThreshold = 128;
    cfg.allowWeakTileUnderlay = false;
    
    // Night Driver
    if (ctx.isNightDriver) {
        cfg.srStripeFilterEnabled = false;   // úplně vypneme
        // nebo cfg.stripeNeighborThreshold = 256; // změkčíme
    }
    
    // Popeye
    if (ctx.isPopeye) {
        cfg.allowWeakTileUnderlay = true;    // povolíme všechny kandidáty
    }
}

5. ZÁVĚR A DOPORUČENÉ DALŠÍ KROKY
--------------------------------------------------------------------------------

Obě chyby jsou čistě na straně emulátoru (ochranné / filtrační mechanizmy) a
NEJEDNÁ SE O CHYBY V SAMOTNÝCH HRÁCH.

Pro Night Driver je klíčové vypnout nebo změkčit SR Stripe Filter.
Pro Popeye je klíčové povolit tile surface underlay i pro slabší kandidáty.

Doporučuje se vytvořit dvě samostatné testovací větve (buildy):
1) BUILD2NIGHT – s vypnutým Stripe Filter (nastavení cfg.srStripeFilterEnabled = false)
2) BUILD2POPEYE – s povoleným underlay pro všechny kandidáty (cfg.allowWeakTileUnderlay = true)

Po jejich otestování bude možné chyby definitivně potvrdit a začlenit do hlavní
větve jako specifické výjimky (podle CRC či velikosti XEX), aby neovlivnily
jiné hry.
