KODY JSOU ZMENENE

Ukol podle Reneho:
- zahodit stare XL RTS/RTI shim vrstvy,
- pouzit natvrdo 130XE OS ROM z NaPatari130xe.rom,
- zadne externi otevirani ROM,
- zadny fake READY/LOAD/SELF TEST, zadny screen paint, zadny RAM inject, zadny opcode $32 patch naslepo.

Pouzita ROM:
- soubor: NaPatari130xe.rom
- velikost: 16384 bytes
- MD5: 06daac977823773a3eea3422fd26a703
- SHA256: a77050b2d81db2d11eaa3dbafd8ec2531b478abcc3bcc4b0d846b634e885edb1

Co bylo fyzicky odstraneno z overlay HTML jako samostatne stare shim scripty:
- FIX352 XL OS STUB RECOVERY PRO TBXL
- FIX354 RTS VYPLN CHYBEJICI XL ROM OBLASTI
- FIX356 RTS PRIMO V CPU CTECI FUNKCI
- FIX357 XL OS SHIM NMI/IRQ PRES RAM VEKTORY
- FIX358 RTI NA INTERRUPT VSTUPECH

Co FIX364 pridava jako posledni vlastnik:
- finalni 130XE OS ROM gate z NaPatari130xe.rom,
- D301/PORTB bit0 prepina OS ROM ON vs RAM pod OS ROM,
- TBXL start s PORTB=$FF: OS ROM ON, BASIC OFF,
- TBXL XEX segmenty do RAM, INITAD volany pres RTS navratovy stub, ne slepy PC skok,
- log FIX364 s ROM hash, PORTB, MEM_6132, RAM_C000, CPU stavem.

Dulezita pravda:
- 130XE OS ROM je tvoje NaPatari130xe.rom.
- Pro POWER BASIC je porad potreba BASIC ROM; ta zustava vestavena z projektu, protoze jsi dodal pouze 16KB OS ROM.
- Hlavni test teto vetve je TBXL na 130XE OS ROM, ne ladeni BASIC ROM souboru.
