AtariHelp.eu EMU-10 BUILD2U_PIXEL_SKIN_CODE
==============================================

Partaku, tohle je oprava po BUILD2T.

CO JE JINAK:
- Tentokrat nejde o polovicaty prepis CSS kresbou.
- Tvoje presne PNG navrhy jsou vlozene jako PIXEL SKIN:
  app/src/main/assets/design/uvodni_np_vision.png
  app/src/main/assets/design/emu_klavesnice_np_vision.png
  app/src/main/assets/design/emu_joystick_np_vision.png
- Nad nimi jsou kodove funkcni vrstvy: pruhledne hit-zony tlacitek, realny canvas emulatoru, realna OSK klavesnice, realny joystick.
- Uvodni obrazovka ma animace v kodu: CRT sweep, scanline/flicker, LED pulse, toceni kotoucu, audio/equalizer pulse.
- Emulatorova obrazovka ma animace v kodu: CRT scanline, jemny sweep, LED pulse.
- Prepinac KEYBOARD/JOYSTICK meni presny skin klavesnice/joystick.
- Jadro emulatoru z BUILD2R zustava v puvodnim JS. Neni prepsane.
- Po otevreni emulatoru se spusti POWER BASIC automaticky pres puvodni tlacitko, aby se objevilo realne READY z jadra.

DULEZITE:
Toto je porad KOD overlay, ne vygenerovany obrazek jako vysledek.
Aby byla kopie opravdu presna na pixel, pouzivaji se tvoje navrhy jako skin obrazky + funkcni kodove vrstvy nad nimi.
Cista CSS/Java kresba nikdy neudela presnou kopii techto bitmapovych detailu bez ztraty vzhledu.

KODY JSOU STEJNE.
BASIC/Altirra testovaci kody se nemenily.

POSTUP PRO RENEHO:
1) ZIP rozbalit.
2) Slozku app prekopirovat pres aktualni projekt.
3) Potvrdit prepsani souboru.
4) Commit v GitHub Desktop:
   BUILD2U pixel-skin exact UI code overlay
5) Spustit GitHub Actions / build APK jako predtim.

   - uvodni obrazovka vypada presne jako navrh
   - po kliknuti na GAMES / TAPE LOADER / PLAY EMULATOR jde emu obrazovka
   - BASIC READY nabehne sam realne pres emulatorove jadro
   - POWER BASIC, SELF TEST, HELP/START/SELECT/OPTION/RESET funguji
   - klavesnice reaguje pres pruhledne hit-zony
   - prepinac KEYBOARD/JOYSTICK prepne skin a joystick reaguje
   - NAHRAJ XEX / ATR / TBXL / TXT / LOG zustavaji dostupne pres pruhledne oblasti
