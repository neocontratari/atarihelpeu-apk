CHECK FIX341 - TBXL_REAL_CLS_INPUT_CORE

Hlavni cil: Turbo Basic XL musi prijmout skutecny prikaz CLS.

1. Otevri EMU-09 FIX341.
2. Klikni "SPUSTIT TBXL 1.5 FIX341".
3. Pockej na READY.
4. Napis rucne C L S a RETURN, nebo klikni "POSLAT CLS PRES KLAVESY".
5. Ocekavani: TBXL prijme prikaz CLS jako Turbo Basic prikaz. Nesmime videt jen opticky READY bez interpreteru.
6. Pri chybe klikni "ULOZIT FIX341 LOG".

Kontrolni radky v logu:
- fix341TbxlActive=YES
- oldFlags fix337=NO fix339=NO fix340=NO
- currentXexName=T-BASIC XL 1.5 FIX341 / real command input core
- FIX341_CIOV_KGETCH_AND_CH_BRIDGE=YES

Poznamka: POWER XL/XE BASIC zustava obycejny Atari BASIC. CLS se testuje az v TBXL.
