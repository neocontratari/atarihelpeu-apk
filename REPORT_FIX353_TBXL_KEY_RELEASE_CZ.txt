AtariHelp.eu EMU-09 - FIX353_TBXL_KEY_RELEASE

KODY JSOU ZMENENE.

Co dokázal test Rene (23:55): obrazovka plná "?" znamená, že celý
řetěz klávesa->CH->TBXL->znak na obrazovce FUNGUJE. TBXL znaky
skutečně vypisuje svým kódem.

Chyba (moje, nalezena v FIX349 deliverKey): po doručení klávesy
se uvolňoval jen SKSTAT, ale KBCODE $D209 zůstal zaseknutý
navždy. TBXL čte KBCODE, vidí věčně stisknutou klávesu a opakuje
znak donekonečna - i bez dotyku (zbytek z minulého testu).

Oprava FIX353:
1. Release timeout (40ms) teď čistí KBCODE + ATACHR + SKSTAT.
   Opraveno na OBOU místech (FIX348 i FIX349 kopie).
2. Watchdog každých 100ms: když je CH spotřebované ($FF) ale
   KBCODE zaseknutý, uvolní ho. Loguje každé čištění.

Test:
1) POWER XL/XE BASIC
2) SPUSTIT TBXL -> titulek, ŽÁDNÉ samovolné znaky
3) Stiskni A -> JEDNO A na obrazovce (ne záplava)
4) PRINT 2+2 + RETURN -> 4
5) CLS + RETURN -> smazaná obrazovka
6) ULOŽIT LOG
