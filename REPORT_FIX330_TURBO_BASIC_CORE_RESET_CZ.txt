AtariHelp.eu EMU-09 - REPORT FIX330_TURBO_BASIC_CORE_RESET

Renemu / testerovi:
Tento overlay vychazi z FIX329, ale FIX329 neberu jako stabilni konec.
Oprava je cilena na Turbo Basic start a BASIC warm reset, bez fake obrazovek a bez RAM programu.

Co bylo spatne ve FIX329:
- FIX329 nahradil window.fix328StartTurboBasic svoji vlastni funkci startTurbo.
- Kdyz pak Turbo tlacitko volalo window.fix328StartTurboBasic, volalo znovu samo sebe.
- Vysledek byla slepa smycka / nespolehlivy start a log typu "captured", ale ne cisty start TBXL.

Co dela FIX330:
- Pridava novy panel "TBXL 1.5 - FIX330 core start".
- Tlacitko se jmenuje "SPUSTIT TBXL 1.5 - FIX330", aby ho stary FIX329 capture regex nezachytil.
- TBXL loader uz nevola fix328StartTurboBasic ani fix329StartTurboBasic.
- Embedded Turbo Basic payload se parsuje primo jako Atari DOS binary:
  - blok $4980-$9B00, delka 20865 bytes
  - INITAD blok $02E2-$02E3 = $6132
  - RUNAD v souboru neni, po relokaci se startuje na $6179 stejne jako predchozi cisty TBXL pokus
- Relokace je stejna jako TBXL INIT rutina:
  - $4900 -> $2000, 0x17 stran
  - $6200 -> $C000, 0x0C stran
  - $6E00 -> $D800, 0x08 stran
  - $7600 -> $E400, 0x1C stran
  - $9200 -> $0B00, 0x07 stran
- PORTB se pri relokaci prepne na $FE pro RAM pod OS ROM a pak zpet na $FF.
- OS ROM gate bere PORTB bit0: kdyz je bit0 low, cteni z OS oblasti jde do RAM, ne do ROM.

BASIC warm reset:
- FIX315 warm reset zustava, ale FIX330 ho obali a po resetu seeduje VIMIRQ:
  - $0216=$30
  - $0217=$C0
  - tedy VIMIRQ -> $C030 po realnem OS IRQ vektoru $C02C
- Pokud nejsou VBI vektory pripravene, FIX330 nenecha bezet predcasne NMIEN.
- Cilem je odstranit pad pres BRK/IRQ do $0000 u BASIC/no-XEX cesty.

Co FIX330 vyslovne nedela:
- NO_FAKE_READY
- NO_FAKE_LOAD
- NO_FAKE_SELF_TEST
- NO_RAM_PROGRAM_INJECT
- NO_SCREEN_PAINT
- NO_RAW_CH_PASTE

Jak testovat:
1. Otevri aplikaci pres novy launcher FIX330.
2. V EMU-09 najdi panel "3) TBXL 1.5 - FIX330 core start".
3. Dej "1) SPUSTIT TBXL 1.5 - FIX330".
4. Pokud se TBXL nechova spravne, dej "2) ULOZIT FIX330 CORE LOG".
5. Ten log se ulozi do mobilu jako FIX330-tbxl-core-reset-log-*.txt.

Ocekavany log po startu:
- FIX330_FIX329_RECURSION_REMOVED=YES
- FIX330_DIRECT_TBXL_XEX_PARSER=YES
- payload: $4980-$9B00 a INITAD $6132
- ENTRY=$6179
- PORTB=$FF po relokaci
- MEM_2000 a MEM_0B00 nesmi byt same nuly
