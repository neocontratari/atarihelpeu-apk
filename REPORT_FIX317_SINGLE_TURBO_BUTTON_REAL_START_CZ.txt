KODY JSOU STEJNE.

Opravy:
- odstraněné duplicitní START+OPTION Turbo Basic tlačítka a snapshot tlačítka v XEX panelu
- FIX316 wrapper nastavoval duplicate guard před voláním FIX315 loaderu, takže loader sám svůj start odmítl; FIX317 starý guard před čistým startem ruší
- zůstává jeden viditelný knoflík: START+OPTION -> TURBO BASIC XL 1.5 XEX — FIX317
- snapshot FIX317 zapisuje počet Turbo tlačítek, stav loaderu, PORTB, MEM_0B00/MEM_2100/MEM_C000/MEM_D800/MEM_E400
- teplý RESET zůstává zachovaný: LIST má přežít, ostrý reset je jen POWER XL/XE BASIC
