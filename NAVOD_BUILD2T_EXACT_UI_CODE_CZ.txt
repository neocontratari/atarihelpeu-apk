ATARIHELP.EU EMU-10 BUILD2T_EXACT_UI_CODE
================================================

Partaku, tohle je opravny overlay po BUILD2S.

HLAVNI ROZDIL:
- Tohle NENI vygenerovany obrazek.
- Je to kod: HTML + CSS + stavajici JavaScript jadro z BUILD2R.
- UI je prepsane podle tvych tri navrhu:
  1) uvodni N&P VISION cerno-zlaty panel s CRT, kazetou, menu a statusem,
  2) emulator joystick varianta Atari 130XE + XC12,
  3) emulator klavesnice varianta Atari 130XE + XC12.

CO JSEM NESAHAL:
- 6502 CPU jadro zustalo z BUILD2R.
- ANTIC/GTIA/PIA/POKEY logika zustala z BUILD2R.
- XEX/ATR/TBXL/TXT loader zustal z BUILD2R.
- Android MainActivity zustala funkcne stejna.

CO JE ZMENENE:
- app/src/main/assets/index.html je nove kodovane uvodni N&P VISION menu.
- app/src/main/assets/emu/index.html ma novy kodovany skin.
- Zachovane jsou vsechny funkcni ID prvky: scr, btnPower, btnSelfTest, btnReset, btnBreak, btnHelp, btnOption, btnSelect, btnStart, btnXex, btnAtr, btnTbxl, btnJoy, btnTxt, btnProgNew, chkOpt, filePick, osk, joy, joyPad, joyKnob, joyFire, log, overlaye.
- Klavesnice je zamcena podle dohodnute Atari 130XE mapy:
  Row 1: Esc, !/1, "/2, #/3, $/4, %/5, &/6, '/7, @/8, (/9, )/0, Clear/<, Insert/>, Delete/Bk Sp, Break.
  Row 2: Clr/Set Tab, Q W E R T Y U I O P, up/- down/=, Return.
  Row 3: Control, A S D F G H J K L, :/;, left/+ right/*, Caps.
  Row 4: Shift, Z X C V B N M, [/,, ]/., ?//, Shift, Fuji/Inverse.
  Row 5: Space.

KODY JSOU STEJNE.
BASIC/Altirra testovaci kody se nemenily.

JAK POUZIT:
1) Zavri Android Studio / emulator build, pokud drzi soubory.
2) ZIP rozbal.
3) Slozku app z overlaye zkopiruj pres aktualni projekt BUILD2R.
4) Potvrd prepsani souboru.
5) Buildni APK stejne jako predtim.
6) Otestuj:
   - uvodni obrazovka musi byt cerno-zlata N&P VISION,
   - PLAY/GAMES otevre emulator,
   - POWER BASIC porad bootuje realny emulator,
   - joystick/keyboard prepinac nesmi rozbit ovladani,
   - XEX/ATR/TBXL/TXT tlacitka musi dal otevirat loader,
   - LOG musi jit ulozit.

POZNAMKA:
Screen emulatoru je porad skutecny canvas z jadra. Neni tam fake READY obrazek.
