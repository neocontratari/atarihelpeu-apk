AtariHelp.eu EMU-09 FIX289_UI_BIND_FILEPICKER_TURBO_SNAPSHOT_CORE

Commit summary:
FIX289: opravuje chaos UI tlačítek po FIX288; Turbo snapshot ukládá přes bridge/download a vlastní BASIC TXT/BAS používá skutečný file picker.

Co se opravilo:
- TurboBasic XEX cesta z FIX288 zůstává: embedded byte-for-byte XEX, bez XHR, segmenty do RAM, INITAD/ENTRY $6132, žádný CLOAD/WAV.
- Tlačítko "2) ULOŽIT / STÁHNOUT SNAPSHOT TURBO XEX" teď nejen zobrazí snapshot, ale pokusí se ho uložit přes Android bridge / saveTextReportToMobile / download link.
- Vlastní BASIC TXT/BAS panel je přepracovaný:
  1) VYBRAT BASIC TXT/BAS ZE SOUBORU otevře mobilní/Nox file picker přes input type=file.
  2) ODESLAT TEXT Z POLE DO BASICU odešle načtený nebo ručně vložený text přes ATASCII/KGETCH helper.
  3) ODESLAT TEXT Z POLE + RUN odešle text a RUN.
- Soubor se po výběru nejdřív načte do textového pole, aby bylo vidět, co se bude posílat.
- Pole je prázdné, žádné přednastavené demo se nedopisuje.
- Viditelné staré FIX248-FIX278/FIX284-FIX288 tagy nejsou v UI.

Co se nedělalo:
- Neřešil jsem ještě grafickou opravu Self Testu. Je veden jako otevřený dluh, bez fake kreslení.
- Neřešil jsem zatím, proč TurboBasic po načtení kreslí strojový obsah jako text / proč CPU steps ve snapshotu zůstávají nízko. To je další fáze: PORTB/D301, OS ROM/RAM pod ROM, BASIC ROM, CPU běh po INITAD.
