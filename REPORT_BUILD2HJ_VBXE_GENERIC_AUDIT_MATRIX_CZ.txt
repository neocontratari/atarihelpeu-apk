CO JE NOVE
1) Obecny VBXE FX core read model podle fx1.26/vbxefx:
   - cteni $D640 vraci CORE_VERSION=$10
   - cteni $D641 vraci MINOR_REVISION=$26 = FX v1.26a
   - cteni $D642/$D643 vraci $FF
   - zapis $D640 zustava VIDEO_CONTROL
   - zapis $D641-$D643 zustava XDL_ADR0-2

2) BUILD2HJ audit matrix pri kazdem VBXE souboru:
   - loguje velikost souboru
   - pocet XEX/OBX segmentu
   - prvni segment
   - INITAD/RUNAD segmenty
   - zda program obsahuje hlasky No VBXE / improper core / Core revision <> 1.20 / VBXE not found

3) OBX podpora v pickeru a ZIP vyberu:
   - .obx se bere jako stejny Atari binarni kontejner jako XEX
   - neni to fake loader ani RAM inject

4) MEMAC bezpecnost:
   - dokumentovany MEMAC je $D64C-$D64F
   - stare/legacy $D65D-$D65F zustava jen opatrny fallback
   - $FF write sweep do $D65D-$D65F se ignoruje jako nebezpecny RMW/sweep, ktery predtim rozbijel mapovani

5) Z predchozich buildu zustava:
   - ZOOM bity z HE
   - source snapshot z HF
   - XDL carry / big-blit z HG
   - NO_PROBE pres Atari z HH
