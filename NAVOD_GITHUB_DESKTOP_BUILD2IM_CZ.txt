NAVOD - BUILD2IM overlay pres GitHub Desktop

1) Zavri Android Studio / emulator, pokud drzi soubory projektu.
2) Rozbal ZIP overlay do korene projektu AtariHelp EMU-10 tak, aby se sloucila slozka app/.
3) Ve Windows potvrdit PREPSAT / SLOUCIT.
4) Otevrit GitHub Desktop.
5) Zkontrolovat zmenene soubory:
   - app/src/main/assets/emu_vbxe/index.html
   - pripadne report/navod soubory v overlay baliku nejsou nutne do projektu, jsou pro kontrolu.
6) Commit message doporucena:
   BUILD2IM VBXE priority XCOLOR safe
7) Build / instalace do Nox nebo mobilu.
8) Testovat presne podle REPORT_BUILD2IM_VBXE_PRIORITY_XCOLOR_SAFE_CZ.txt.

DULEZITE
- BUILD2IM navazuje na BUILD2IL, protoze BUILD2IL odstranil HL sedy obdelnik.
- Pokud se HL obdelnik vrati, BUILD2IM je regression a vratit se k BUILD2IL.
- Pokud HL zustane dobry a ostatni se posunou, dalsi krok je MAP/attribute/timing audit.
