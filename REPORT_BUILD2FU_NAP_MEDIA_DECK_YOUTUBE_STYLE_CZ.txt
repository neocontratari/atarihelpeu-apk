- pouzita je tmava gold/blue high-res stylizace s pozadim z uvodniho skinu

- SYSTEM zustava vstup do emulatoru

TEST PLAN
1. Spust aplikaci.
2. Klikni TAPE LOADER.
3. Ocekavany stav:
   - otevre se stylovy N&P popup MEDIA DECK
   - ne obycejne textove okno
4. Klikni PRIDAT MP3 / WAV.
   - musi jit vyber souboru z mobilu/NOX
5. Klikni YOUTUBE.
   - musi se otevrit https://www.youtube.com/
6. Klikni ZAVRIT.
   - popup se zavre
7. Klikni SYSTEM.
   - musi otevrit emulator
