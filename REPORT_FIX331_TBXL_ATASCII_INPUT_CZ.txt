AtariHelp.eu EMU-09 FIX331_TBXL_ATASCII_INPUT
Datum: 2026-06-09

Co opravuje:
- FIX330 dokazal dostat Turbo Basic XL 1.5 na obrazovku READY, ale klavesnice zustala v XEX/game scan-code ceste.
- Proto neslo normalne psat a RETURN po radku dokazal TBXL zablokovat.

Zmena ve FIX331:
- FIX330 loader zustava zachovany.
- Po startu TBXL se zapne samostatny ATASCII input bridge jen pro TBXL.
- RETURN se posila jako ATASCII $9B.
- Pismena/cisla/symboly jdou pres CH/KBCODE/OS keyboard vector ve tvaru, ktery BASIC ceka.
- TBXL se kvuli psani neprepina natvrdo do cele REALOS pametove mapy.

Zasady:
- NO_FAKE_READY=YES
- NO_FAKE_LOAD=YES
- NO_FAKE_SELF_TEST=YES
- NO_RAM_PROGRAM_INJECT=YES
- NO_SCREEN_PAINT=YES
- KODY JSOU STEJNE

Test pro Reneho:
1. Spustit EMU-09 FIX331 Turbo Basic + ATASCII vstup.
2. Pockat na READY.
3. Na mobilni klavesnici napsat:
   PRINT 1
4. Stisknout RETURN.
5. Spravne chovani: TBXL vypise 1 a vrati se na READY.

Kdyz se to zasekne:
- Stisknout "2) ULOZIT FIX331 ATASCII LOG".
- Poslat ulozeny TXT log z AtariHelpLogs.
