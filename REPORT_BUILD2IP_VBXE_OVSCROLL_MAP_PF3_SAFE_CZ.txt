AtariHelp.eu EMU-10 VBXE - BUILD2IP_VBXE_OVSCROLL_MAP_PF3_SAFE
======================================================================

Zaklad:
- Navazuji na otestovany BUILD2IO, ktery Rene potvrdil jako bezpecny smer:
  HL bez sedeho obdelniku, Popeye se pohnul dopredu, W3D ma rozdil LOW/HIGH,
  Textmode je ostrejsi.
- BUILD2IN zustava pozastaveny, nepouzivat jako zaklad.
- BUILD2IH/BUILD2IK blank-hold/last-good vetev NEvracim.

Co se meni:
1) OVSCRL pro graficky overlay
   - OVSCRL se ted nepouziva jen jako parsed stav, ale realne se aplikuje pri cteni
     SR/LR/HR grafickych dat z overlay surface.
   - Zavedene helpery:
       vbxeGraphLocalY()
       vbxeGraphSourceAddr()
       vbxeGraphHScrollHi()
   - Cilem je obecne zlepsit zarovnani overlay obrazu, clipping a surface cteni.
   - To muze pomoct hlavne Commando / Postcard / Popeye / W3D / Textmode levy okraj.

2) Attribute map PF3 oprava
   - BUILD2IO prebarvoval PF0/PF1/PF2, ale v nekterych mistech se PF3 choval jako PF2.
   - BUILD2IP nechava PF3 globalni, protoze VBXE map field v dokumentaci resi lokalni
     COLPF0, COLPF1, COLPF2 + prioritu/palety, ne slepe PF3=PF2.
   - Cilem je mene rozbite ANTIC+VBXE kompozice, hlavne Postcard a tmave/plne plochy.

Co se NEMENI:
- UI skin, joystick, klavesnice, hitboxy.
- NET HRY / XEX / ATR / Turbo BASIC / BASIC TXT / LOG / HELP / MENU.
- RAM320.
- BCB chain limit 1024.
- HR canvas 640.
- Zadny hack podle nazvu hry.
- Zadny fake obraz, zadne rucni kresleni Arnolda/Popeye/HL.
