N&P VISION — PRO DJ MIXER (fotorealistický, BUILD2SK1)

Pult vypadá přesně jako tvůj grafický návrh — obrázek je pozadí, ovládání jsou neviditelné dotykové zóny (jako celá appka). Zvuková logika je beze změny.

Rychlý start

USB 1 (nebo obal skladby) → playlist → + PŘIDAT → vyber MP3 → ▶III. Druhý deck přes USB 2. Crossfader dole uprostřed, A/B = tvrdý střih.

Co kde je

Fader 1/2 = hlasitost decků · MASTER uprostřed = celková · TEMPO po stranách ±8 % (RESET, −/+ = 0,5 %, KEY LOCK drží tóninu) · SYNC srovná tempo podle druhého decku · TAP = vyťukej BPM.

Ozubené kolo u decku / EFFECTS → 10pásmový EQ (31 Hz–16 kHz, ±12 dB, VYNULOVAT). HIGH/MID/LOW mini fadery = rychlé EQ skupiny. FX ON + velký FX fader = lowpass filtr.

Waveform: klepnutí = skok ve skladbě. Pady: 1. klep uloží bod, další skočí, podržení smaže (DELETE = mazací režim). LOOP: začátek → konec → vyp. RECORD: nahraje mix do souboru.

SETTINGS/ozubené kolo nahoře → ASISTENT (ty jsi šéf: vypnutí podržením 1,6 s, POLOAUTO/AUTOMAT). MENU/vypínač → zpět do appky. HELP → tahle nápověda přímo v pultu.

Kalibrace

3× klepni na logo N&P uprostřed → červeně se zvýrazní všechny dotykové zóny. Když někde klik nesedí, vyfoť to a pošli — posunu souřadnice.
