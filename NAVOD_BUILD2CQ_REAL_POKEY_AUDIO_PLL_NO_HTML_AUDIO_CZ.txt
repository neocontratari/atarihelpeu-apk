AtariHelp.eu EMU-10 BUILD2CQ_REAL_POKEY_AUDIO_PLL_NO_HTML_AUDIO
=====================================================================

René, tohle je opravný overlay po tvé výtce k BUILD2CP.
Beru to jako důvěrový build: žádné lakování ROM, žádná výmluva na BASIC text.
ROM v logu bootuje jako pravá XL OS 16K + Atari BASIC 8K. Chyba byla v naší POKEY/kazetové vrstvě.

ZÁKLAD
------
BUILD2CQ vychází z BUILD2BZ/BY golden.
BUILD2CK není použitý jako základ.
TXT fronta, joystick, scroll a focus nejsou měněné.

KODY JSOU STEJNE.

CO BYLO ŠPATNĚ PŘEDTÍM
----------------------
BUILD2CO/CP sice vypínal raw SERIN zkratku, ale pořád byla kazetová cesta nedotažená:
- PCM/SKSTAT běžel,
- slyšitelný monitor se řešil zvlášť,
- POKEY serial input receiver z reálných audio hran nebyl hotový.

To znamená: ROM nečetla reálný proud tak, jako ho má dostat přes POKEY.
Tvoje připomínka, že bez správného POKEY/zvuku nemá CLOAD smysl, byla správná.

CO JE ZMĚNĚNÉ V BUILD2CQ
------------------------
1) WAV/HTML Audio pro CLOAD je fyzicky vypnuté.
   WAV soubor se po vložení NEpřipojuje do Android HTML Audio elementu.
   Tím nejde vzniknout druhému zvuku ani druhému časovači.

2) Jediná cesta pro WAV CLOAD je:
   skutečný WAV PCM tvar -> SKSTAT bit4 -> POKEY-like PLL/serial receiver -> SERIN IRQ $20.

3) POKEY RX je nový:
   - bere hrany ze stejného PCM/SKSTAT toku,
   - skládá 600 baud async serial: 1 start bit, 8 datových bitů LSB first, 1 stop bit,
   - první start-bit se fázově zamkne po leaderu,
   - další byty běží po 10 bitech jako POKEY serial receiver,
   - SERIN read shodí jen IRQST serial-input-ready $20, ne falešné output-needed $10.

4) Raw SERIN zkratka zůstává vypnutá.
   Pokud se objeví starý log CLOAD SERIN ARM u LAST CSAVE WAV testu, je to chyba.

5) CSAVE WAV log už správně hlásí amplitudu 60 %, ne 0 %.

6) Písmo a věrnější READY charset nejsou zapomenuté.
   V tomhle buildu se ale záměrně nemění, protože teď se opravuje kazeta/POKEY.

TEST PLÁN
---------
1) Nahraj overlay BUILD2CQ přes GitHub Desktop stejně jako předchozí buildy.
2) Spusť aplikaci.
3) POWER -> BASIC.
4) BASIC TXT vlož stejný delší testovací program jako minule, dej VLOŽIT + RUN.
5) Po dopsání programu udělej CSAVE / SAVE "C:" stejně jako dosud.
6) Nech auto-save dokončit CAS+WAV.
7) Vlož LAST CSAVE WAV nebo použij stejný workflow jako minule.
8) V BASICu dej CLOAD a PLAY.

KDYŽ TO SELŽE
-------------
Pošli log od řádku:

AtariHelp.eu EMU-10 BUILD2CQ_REAL_POKEY_AUDIO_PLL_NO_HTML_AUDIO pripraven.

nebo aspoň od:

VLOZIT KAZETU BUILD2CQ: WAV ... vlozen BEZ Android HTML Audio

po ERROR 138 / ERROR 21 / ERROR 130.

Hlavně mě bude zajímat:
- jestli POKEY TAPE RX vůbec našel první byte,
- kolik audio->SERIN bytů prošlo,
- jestli je OVERRUN,
- kde je PC při chybě,
- jestli už se neobjevuje druhý KAZETA PLAY zvuk.

POZNÁMKA PRO DALŠÍ PRÁCI
------------------------
Jakmile bude CLOAD stabilní, další samostatný build bude:
- READY/Atari charset/CHBASE písmo,
- potom věrnější XC12/FSK monitor zvuk.

Teď je priorita: čistý POKEY kazetový vstup, bez fake, bez dvou zvuků, bez raw SERIN zkratky.
