AtariHelp.eu EMU-10 BUILD2BL_CLOAD_WAV_PCM_SKSTAT_VOLUME_FIX
=============================================================

KODY JSOU STEJNE.
Jadro/ROM/BASIC testovaci kody se nemenily. Zmena je v kazetove CLOAD/CSAVE ceste a zvuku WAV.

Proc tento build vznikl:
- BUILD2BJ porad nebyl viditelny posun v CLOAD.
- Log ukazal, ze posilani hotoveho bytu do POKEY SERIN bylo spatne: OS ho necetl.
- Pri kontrole OS ROM rutiny se ukazalo, ze CLOAD kod na $ED44 cte SKSTAT $D20F bit4 a meri hrany tonu.
- Proto BUILD2BL prestava krmit CLOAD hotovymi SERIN bajty a vyrabi z realnych dat tonovy bitstream 3995/5327 Hz na SKSTAT bit4.

Co je zmeneno:
1) CLOAD vstup:
   - CAS/WAV/last CSAVE data nejdou jako hotove SERIN bajty.
   - Data se meni na realny kazetovy bitstream: leader 5327 Hz, start bit 3995 Hz, data bity 3995/5327 Hz, stop bit 5327 Hz.
   - Bitstream je viditelny pro OS pres SKSTAT bit4, ktery realna OS ROM pri CLOAD skutecne cte.
   - Spousti se az po realnem C: motor ON z PACTL.
   - Zadny RAM inject, zadne cteni BASIC programu z RAM.

2) CSAVE WAV zvuk:
   - Render ulozeneho WAV je zvednuty na 44.1 kHz.
   - Misto hrube ctvercove vlny je pouzit plynulejsi sinusovy ton 3995/5327 Hz.
   - Cilem je, aby zvuk nebyl tak prervany a vic se blizil realne kazete.

3) Log:
   - Pribyly zpravy CLOAD BITSTREAM BUILD2BL.
   - Dulezite hledat:
     * QUEUE_TONE / CLOAD BITSTREAM pripraven
     * MOTOR_OK_LEADER
     * BITSTREAM_DATA_START
     * BITSTREAM_COUNT
     * BITSTREAM_COMPLETE

Test plan:
1) POWER BASIC -> READY.
2) START+OPTION -> overit, ze boot pokus je porad lepsi nez drive.
3) Vlozit velky WAV (napr. galactic/pacman) -> PLAY -> hlavne overit zvuk a ze apka nespadne.
4) Udelat maly BASIC program a CSAVE.
5) Po ulozeni zmacknout LAST CSAVE / SAVE, tim se vlozi posledni realne nahrany WAV z pameti.
6) V BASICu napsat CLOAD a dat PLAY.
7) Poslat log, pokud nenacte. Nejdulezitejsi bude, jestli se v logu objevi BITSTREAM_COUNT a jestli PC uz nelezi porad ve stejne smycce.

Poznamka:
- Tohle je poctivejsi oprava nez predchozi SERIN pokusy. Nemusi byt jeste finalni, protoze presne hrany 3995/5327 Hz jsou v JavaScript/WebView emulaci zatim aproximovane po scanlinech. Ale smer je spravny: OS CLOAD dostava to, co skutecne cte - SKSTAT bit4 hrany tonu.
