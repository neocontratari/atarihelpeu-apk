ATARIHELP.EU EMU-09 - REPORT FIX338_TBXL_CPU_CIOV_INPUT_FIX

KODY JSOU ZMENENE.

CIL:
- Rozjet Turbo Basic XL tak, aby necyklil READY a slo do nej psat.
- Zachovat primy TBXL XEX loader z FIX337.
- Bez fake READY, bez fake LOAD, bez screen paint, bez RAM program inject.

CO SE ZMENILO:
- Pridan CPU-level bridge pro TBXL vstupni rutiny.
- FIX337 mel blokujici CIO/KGETCH sluzbu, ale TBXL ma presunutou cast OS/CIO kodu do vlastnich oblasti, proto stara ochrana pres loadedXexByteAt hook obchazela.
- FIX338 chyta primo instrukci JSR $E456 / $E420 v Turbo Basic CPU toku.
- Output prikazy se nechavaji bezet pres TBXL kod; bridge chyta jen input prikazy CIO GETREC/GETCHARS a KGETCH.
- Pri prazdne fronte CPU zustane na skutecnem JSR vstupu, takze se nevraci prazdna radka a READY se nema tocit porad dokola.
- Po napsani textu a RETURN se radka pusti do realne TBXL E: input cesty.

TEST PLAN:
1. Nahrat ZIP overlay pres GitHub Desktop.
2. Spustit aplikaci.
3. Kliknout: SPUSTIT TBXL 1.5 FIX338.
4. Pockat na TBXL READY.
5. Zkusit napsat pres mobilni Atari klavesnici:
   PRINT 2+2
   RETURN
6. Ocekavani: READY se nema sam porad cyklit; po RETURN se ma prikaz predat Turbo Basicu.
7. Potom zkusit:
   10 PRINT "AHOJ"
   RETURN
   RUN
   RETURN
8. Kdyz bude chyba, ulozit: ULOZIT TBXL LOG FIX338.

HLIDAT V LOGU:
- build=FIX338_TBXL_CPU_CIOV_INPUT_FIX
- FIX338_CPU_LEVEL_TBXL_INPUT_BRIDGE=YES
- bridgeHits > 0
- pri cekani na klavesu bridgeBlocks > 0
- po RETURN bridgeReturns > 0
- keyQueued > 0 po stisku klaves
- CORE LOADER INFO musi zustat STREAMED=OK ACTIVE=YES

POZNAMKA:
Tento FIX neni univerzalni XEX loader pro vsechny hry. Je to oprava Turbo Basic vstupu nad existujicim FIX337 direct loaderem. Dalsi krok po potvrzeni TBXL bude obecny XEX loader pod kapotu.
