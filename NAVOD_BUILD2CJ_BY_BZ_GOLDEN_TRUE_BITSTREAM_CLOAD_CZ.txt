AtariHelp.eu EMU-10 BUILD2CJ_BY_BZ_GOLDEN_TRUE_BITSTREAM_CLOAD

KODY JSOU STEJNE.
Zaklad: BUILD2BZ/BY golden.
TXT line queue z BUILD2BZ NEMENEN.
Joystick/scroll/focus z BUILD2BY NEMENEN.

Proc vznikl BUILD2CJ:
BUILD2CI skoncil Error 21, protoze SKRES requeue byl spatny smer. OS zapisuje SKRES normalne a build CI porad vracel prvni bajt $FC zpet do fronty, takze CLOAD nikdy nezacal.

Co meni CJ:
- vlastni LAST CSAVE uz nejde jako hotove SERIN bajty,
- jde jako skutecny 600 baud FSK bitstream na SKSTAT bit4,
- ROM musi precist leader, $55, control, 128 dat a checksum sama,
- zadny RAM inject, zadne cteni BASIC programu z RAM, zadny fake CLOAD.

Test:
1) POWER -> READY
2) BASIC/TBXL TXT -> vlozit stredni test
3) VLOZIT + RUN -> musi vypsat SUM OK a KONEC OK
4) CSAVE -> cekat CSAVE VYSLEDEK: ANO
5) LAST CSAVE / SAVE
6) NEW, LIST musi byt prazdny
7) CLOAD, PLAY
8) Po READY: LIST a RUN

Log markery:
CLOAD TRUE BITSTREAM BUILD2CJ
FSK odtika
FSK stream dokoncen

Kdyz selze, poslat log a napsat: CJ 138, CJ 21, nebo CJ ZVUK.
