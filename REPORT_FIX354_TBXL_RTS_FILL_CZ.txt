AtariHelp.eu EMU-09 - FIX354_TBXL_RTS_FILL

KODY JSOU ZMENENE.

Z logu Rene (2026-06-10 01:00):
- Oprava zaseknuté klávesy DRŽÍ (žádná záplava znaků).
- RETURN doručen, TBXL zpracoval, FIX352 stub zachránil pád
  ($C9C6 -> RTS $608F).
- Problém: stub jede přes polling 25ms. TBXL volá $C9C5 při
  každém znaku => každý znak čeká až 25ms => systém leze,
  působí mrtvě.

Oprava FIX354:
ROM je v tomto jádru mapovaná do pole ram[]. Chybějící XL OS
oblast $C000-$CFFF (teď garbage $02) se po detekci TBXL naplní
instrukcí RTS ($60). Každé volání do prázdné ROM se vrátí
OKAMŽITĚ - žádný trap, žádné čekání, plná rychlost.
Bezpečnost: před výplní se oblast zkontroluje - pokud obsahuje
skutečná data, výplň se NEPROVEDE a jede dál FIX352 stub.

Test:
1) POWER XL/XE BASIC
2) SPUSTIT TBXL -> titulek
3) V logu musí být: "XL ROM oblast $C000-$CFFF vyplněna RTS"
4) Stiskni A -> jedno A okamžitě
5) PRINT 2+2 + RETURN -> 4
6) CLS + RETURN
7) ULOŽIT LOG
