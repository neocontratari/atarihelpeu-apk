REPORT FIX262 - CASSETTE AUDIO VISIBLE WAV TO POKEY CORE

Commit summary:
FIX262 cassette audio visible WAV to POKEY core

Zmeny:
1) Stabilni UI z FIX261 zustava, finalni FIX262 relock bezi i po starych delayed stampech.
2) Kazeta je jeden cisty panel pod klavesnici.
3) Built-in TurboBasicXXL.wav se nacita robustne bez query parametru; fallback fetch -> XHR -> file:///android_asset.
4) Pridan realny HTML5 audio prehravac + progress bar + motor/audio stav.
5) Pridan ZVUK TEST BEEP pro overeni, jestli Nox/WebView/system zvuk vubec hraje.
6) WAV se parsuje jako RIFF/PCM a dekoduje na serialni bajty z FSK signalu.
7) CLOAD + PLAY + POKEY typuje CLOAD do skutecneho BASICu pres existujici frontu a zapne POKEY SERIN hook.
8) POKEY hook vraci dekodovane bajty pres SERIN $D20D a IRQST $D20E, bez RAM injectu.
9) Snapshot FIX262 vypisuje audioReady, playing, motor, duration, decode status, serialPtr, IRQreads, SERreads a pravidlo NO_FAKE_LOAD/NO_RAM_INJECT.

Riziko:
Prvni serialni cassette hook nemusi jeste trefit vsechen ROM timing. Jestli CLOAD zustane viset, potrebuju snapshot po 10-30 sekundach CLOAD+PLAY: podle IRQreads/SERreads uvidime, jestli OS cte POKEY a jestli se maji zpomalit/zrychlit byteDelaySteps nebo doplnit IRQEN/SKCTL chovani.
