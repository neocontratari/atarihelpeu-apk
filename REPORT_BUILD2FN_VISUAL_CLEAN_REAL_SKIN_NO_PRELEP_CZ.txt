KODY JSOU STEJNE.

Tento overlay je navazujici cista graficka oprava po BUILD2FM.
Nesahano na CLOAD, POKEY, CSAVE, TXT zapis, ROM, CPU, Java ani Android bridge.
Meni se jen PNG skin a HTML build popisky.

CO BYLO OPRAVENO:
1) Uvodni menu - karta EMULATOR
   - odstranena cerna nalepena vypln / dojem tlacitka pres tlacitko.
   - karta je znovu postavena z puvodni textury stare APK.
   - text a ikona jsou kreslene primo do PNG skinu.
   - HTML odkaz #goTape zustava pouze neviditelna klikaci zona.

2) Emulator - START+OPTION
   - odstranena cerna nalepena plocha uvnitr druheho power tlacitka.
   - tlacitko ma puvodni realnou texturu/bevel ze stare APK.
   - napis START + OPTION je kreslen primo do PNG, lehcim fontem podle POWER BASIC.
   - HTML button #btnSelfTest zustava pouze neviditelna hitzona.

3) Funkce zustava z BUILD2FL/BUILD2FM
   - TXT zapis zustava stejny.
   - CLOAD/CSAVE/START+OPTION logika zustava stejna.
   - MP3 playlist a hlavni menu funkce zustavaji stejne.
