B292 - nove jadro Atari 130XE presne po cyklech (testy na obycejnem Linuxu s g++)
==================================================================================

Spoustet z adresare test_overeni/b292. Prekladaji se jen hlavicky jadra
(nap_atari_6502.h, nap_atari_machine.h, nap_atari_tape.h, nap_atari_vbxe.h,
nap_atari_runtime.h).

1) Jadro na PC (boot, Acid800, XEX, ATR, kazeta):
   g++ -std=c++17 -O2 -I../../app/src/main/cpp/atari -o test_core test_core.cpp
   ./test_core boot                         -> start OS s BASICem, READY
   ./test_core acid acid800.atr             -> Acid800 (DETAIL=1 / TEXTLOG=1)
   ./test_core xex hra.xex 1500 prefix 300,600  -> snimky obrazu:
                                               *.idx 384x240 (kod barvy GTIA, srovnani s atari800)
                                               *.ppm 768x240 RGB (B296: i obraz z VBXE)
   ./test_core atr disketa.atr 1500 prefix 300,600   -> totez se startem z D1:
   ./test_core kazeta [vystup.wav] [vstup.wav]  -> CSAVE -> WAV -> CLOAD -> LIST
   ./test_core kazeta-dlouha basic 12        -> B298: dlouhy program napsany na
   ./test_core kazeta-dlouha tbxl 10            klavesnici -> LIST (= zdroj) -> CSAVE ->
                                               WAV -> novy stroj -> CLOAD -> pamet i LIST
                                               stejne (VYSTUP_test_core_kazeta_dlouha.txt)
   ./test_core bootkazeta synt|synt-stereo|x.wav -> B298: kazeta s hrou (boot):
                                               START+OPTION pri zapnuti, RETURN po
                                               pipnuti (KazetaBoot jako v appce);
                                               synt = kazeta ze syntaz_kazeta.h
   ./test_core pc-klavesnice [naivne]       -> B302: klavesnice pocitace (prohlizec na TV/PC)
                                               -> Atari: nap::PcKlavesnice (mapovani, PSANI/
                                               HRANI, drzene klavesy, hlidani spojeni) +
                                               nap::PcPrehravac (tempo pro OS: KEYDEL, CH).
                                               Radky napsane vsemi klavesami NARAZ, cesky,
                                               AltGr, CapsLock, sipky, BREAK, joystick ...
                                               "naivne" = klavesy hned, jak prijdou (bez
                                               tempa) - dukaz, ze se pak znaky ztraceji
                                               (VYSTUP_test_core_b302_pc_klavesnice*.txt)
                                               Prohlizec (Chromium) -> C++: ../b302
   ./test_core pokey-casovac                -> B300: perioda preruseni casovace 1 pro AUDF
                                               0..$FF na 1,79 MHz (AUDF+4) i 64 kHz ((AUDF+1)*28);
                                               do B299 AUDF=$FF nevystrelil nikdy (Ghostbusters)
                                               (VYSTUP_test_core_b300_pokey_casovac.txt)
   ./test_core txt-program zkouska basic|tbxl  -> B299: TXT soubor -> klavesy do Atari
   ./test_core txt-program x.txt basic|tbxl [list.txt]    (nap::PsaniProgramu jako v appce),
                                               pak LIST a srovnani se souborem
                                               (VYSTUP_test_core_b299_txt_basic/tbxl.txt)
   ./test_core tbxl-disketa [stary]         -> B299: Turbo-BASIC XL + disketa v D1:.
                                               TBXL ma v RAM pod ROM na $E459 vlastni kod;
                                               "stary" = SIO zkratka i bez ROM (chyba do
                                               B298: LIST i RUN rozsypane), bez = B299
                                               (VYSTUP_test_core_b299_tbxl_disketa*.txt)
   ./test_core kazeta-list x.wav basic|tbxl out.txt    -> B299: CLOAD ciziho WAV a cely LIST
   ./test_core kazeta-run-list x.wav break|reset N out -> CLOAD, RUN, po N snimcich BREAK/RESET, LIST
   ./test_core kazeta-fuzz x.wav pokusu seed           -> stav po CLOAD (TBXL), LIST v nahodnem
                                               okamziku s nahodne drzenymi klavesami
   ./test_core kazeta-fuzz-cload x.wav pokusu seed vzor.txt -> cely postup jako na telefonu
                                               (TBXL, CLOAD, kazeta po pipnuti, RETURN,
                                               STOP, LIST) s nahodnym casovanim
   ./test_core kazeta-trace x.wav "LIST 1000"  -> kudy jde TBXL pri LIST (adresy, volani E:)
   ./test_core kazeta-dump x.wav tbxl ram.bin  -> CLOAD, LIST a cela RAM (vc. RAM pod ROM)
   ./test_core kazeta-diag x.wav tbxl          -> radky "B299 PAMET" jako LOG/CHYBA v appce.
                                               Reneho WALLS (TBXL po CLOAD) na PC:
                                               program VNTP..STARP 4417 B crc32 FD64788B,
                                               RAM pod ROM $C000-$CFFF B12E07AB,
                                               $D800-$FFFF FDEB45A2, $2000-$3FFF 8796F47A
   ./test_core xe130                        -> B293: kontrola veci, ktere ma 130XE
                                               jinak nez Atari 800 (banky, ANTIC/CPU
                                               pristup, TRIG3, RESET, self-test ROM...)
   acid800.atr je v repozitari emulatoru atari800 (test/acid800.atr).

   B296 - vstupy pro xex/atr (promenne prostredi):
     KLAVESY="snimek:kod,..."  klavesa (kod 0-63, +64 SHIFT, +128 CTRL),
                               1000 = START, 1001 = FIRE
     JOY="od-do:maska,..."     joystick 1 drzeny ve snimcich od..do
                               (1 nahoru, 2 dolu, 4 vlevo, 8 vpravo, 16 FIRE)
   Priklady (VYSTUP_test_core_vbxe.txt):
     KLAVESY="400:33,1600:1000,1800:1001" JOY="1900-2600:4" \
       ./test_core xex "../../test_assets/Popeye (VBXE, PAL Version)(2).xex" 2600 pop 1500,2600
     KLAVESY="400:33,700:12,900:12,1100:12,1570:33" JOY="1500-1560:1" \
       ./test_core atr "../../test_assets/wolf3d(1).atr" 1700 w3d 300,1400,1560,1700
   Na konci a u kazdeho ulozeneho snimku vypise stav VBXE (zapisy, XDL,
   rezim overlay, MEMAC, pocet blitu, IRQ, radku kreslenych pres VBXE).
