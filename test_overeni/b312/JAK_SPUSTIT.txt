=======================================================================================================

Kod v appce:
  assets/player/index.html        RECORD = mixtape (MediaRecorder za EQ / BASS / TREBLE / BALANCE, pred

                                  MENU / ZPET / 90 min), FAVORITES (hvezdicky, panel, localStorage, HRAT

  java/.../NapPravidla.java       ciste rozhodovani: ktera stranka je SEGA / PS1, zamceno, duvod (slova jako
                                  menu), hudba v seznamu (i M4A / WebM ...), stranky se ZPET
  java/.../MainActivity.java      konzoleZamcena + brany ve vsech cestach ke hre Segy / PS1 (stazeni z webu,
                                  ZIP s ROM, AHPS1.ps1DownloadAndBoot, ps1PickGame), zamcena stranka emulatoru

                                  servisZbyva, odemkniDalsi / zamkniVse jen s otevrenym servisem, ZPET pro
                                  MP3 / DZUBOX (napZpet), seznam hudby i M4A / OGG / FLAC / WebM
  smazano                         nepouzite obrazky design/ (6), img/logo.png, img/pecet.png,

  C++                             beze zmeny (testy C++ z B311 a starsich plati dal)

Spoustet z adresare test_overeni/b312 (nebo odkudkoli: bash test_overeni/b312/vse.sh).
Potreba: JAVA_HOME = JDK (javac, java), Python 3, Chromium + Playwright pro Python, ffmpeg / ffprobe
(s libmp3lame - pisnicky do testu), android.jar API 34 ($ANDROID_JAR, napr. z github.com/Sable/
android-platforms android-34/android.jar - jen jako classpath pro javac).
Vse najednou: PRAC=... ANDROID_JAR=... [NAP_SERVIS_KOD=...] bash vse.sh      (vystupy VYSTUP_* sem)
NAP_SERVIS_KOD = skutecny servisni kod (zna ho jen Rene; v repozitari neni) - s nim JVM test overi i otisk
v appce a bod 10 overi, ze kod v repozitari neni. Kod se nikam nevypisuje.
