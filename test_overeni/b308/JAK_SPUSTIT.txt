Spoustet z adresare test_overeni/b308 (nebo odkudkoli: bash test_overeni/b308/vse.sh).
Potreba: gcc / g++, aarch64-linux-gnu-gcc + qemu-aarch64 (NEON jako v telefonu), JAVA_HOME = JDK,
hlavicky EGL / GLES2 / KHR v $INC (jako ../b304), knihovny Mesa (libEGL, libGLESv2),
Python 3 + numpy + Pillow, Chromium + Playwright pro Python, git (stary psx_gpu_parse.c z B307).
Vse najednou: PRAC=... INC=... bash vse.sh   (vystupy VYSTUP_* sem, cesty v nich zkracene na PRAC / REPO)

Prepinac PS1 = -DANDROID -I../b305/stub -I../b291/stub -I$INC -I$JAVA_HOME/include -I$JAVA_HOME/include/linux
(../b305/stub = nahrada OpenSL ES a Android, ../b291/stub = Android)

1) DOOM - skutecny graficky cip appky (gpulib + gpu_neon z vendor/pcsx_rearmed), stejne prepinace
   jako appka; s opravou (soucasny strom) a bez ni (psx_gpu_parse.c z commitu 64e47dd = B307),
   x86 (SSE) i arm64 (NEON pres qemu-aarch64):
   python3 kontrola_doom.py PRAC/doom                                -> VYSTUP_kontrola_doom.txt
     gpu_doom.c = sceny poslane do GPU jako z PSX Doomu (podlaha a strop po radcich 1 bod -
     POLY_FT3 (L,y) (R,y) (R,y+1), zdi po sloupcich 1 bod, postavy, stavovy radek, nebe jako SPRT),
     "tenke" = nahodne tenke primitivy jako Doom, "nahodne" = primitivy ostatnich her.
     Meri: diry a body navic proti puvodnimu PS1 (1x zvetsene 2x), jina barva, bit po bitu shoda
     ostatnich her s opravou i bez ni, arm64 = x86, rychlost (600 snimku).
2) DENIK PS1 + klavesnice z TV + zamek retro_run - SKUTECNY nap_ps1_native.cpp (ps1_harness.cpp:
   misto PCSX "hra" 320x240 se zmenami obrazu, hlaskami jadra a pametovou kartou):
   g++ -std=c++17 -O2 -shared -fPIC -pthread $PS1 -o PRAC/libps1_b308.so ps1_harness.cpp \
       -Wl,--no-undefined -l:libEGL.so.1 -l:libGLESv2.so.2
   python3 test_ps1_denik.py PRAC/libps1_b308.so PRAC/denik         -> VYSTUP_test_ps1_denik.txt
                                                                       + UKAZKA_denik_ps1.txt (cely denik)
3) ThreadSanitizer: vlakno emulace, zvukova karta, 2 vlakna prohlizece s klavesami, stranka cte denik,
   SAVE / LOAD pozice, dotyk, zmeny obrazu, hlasky jadra - 7 s soubezne:
   g++ -std=c++17 -O1 -g -fsanitize=thread -pthread $PS1 -o tsan_denik tsan_denik.cpp -l:libEGL.so.1 -l:libGLESv2.so.2
   TSAN_OPTIONS="halt_on_error=0 report_signal_unsafe=0 detect_deadlocks=0" ./tsan_denik PRAC/tsan
                                                                    -> VYSTUP_tsan_denik.txt
