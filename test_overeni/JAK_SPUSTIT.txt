Jak znovu spustit tenhle test (na jakemkoli Linuxu s g++):

  g++ -DPOUZIT_STAROU_VERZI -o test_stara test_memcard_wiring.cpp
  g++ -o test_nova test_memcard_wiring.cpp
  ./test_stara
  ./test_nova

Presny vystup z posledniho spusteni je v VYSTUP_TESTU.txt.

  g++ -std=c++14 -o test_e2e test_end_to_end.cpp
  ./test_e2e

Treti test (B218, jedna trvala karta - AKTUALNI, autoritativni test):
  g++ -std=c++14 -o test_jedna_karta test_jedna_karta.cpp

Tenhle test navic ulozi syrovy obrazek klavesnice (co by normalne videl
telefon) do /tmp/kbd_render.rgb (+ *_pressed.rgb pro zmacknuty/zamceny
stav) - prevod na PNG pro skutecne vizualni prohlednuti:
  python3 -c "from PIL import Image; Image.frombytes('RGB',(471,836), \
    open('/tmp/kbd_render.rgb','rb').read()).save('/tmp/kbd_render.png')"

realneho telefonu (zadny NDK/Android build neni v tomto kontejneru
k dispozici - skutecny arm64 preklad dela az GitHub Actions).
