Spoustet z adresare test_overeni/b311 (nebo odkudkoli: bash test_overeni/b311/vse.sh).
Potreba: g++, JAVA_HOME = JDK (javac, hlavicky JNI), hlavicky EGL / GLES2 / KHR v $INC (jako ../b304),
knihovny Mesa (libEGL, libGLESv2), Python 3 + Pillow, Chromium + Playwright pro Python, ffmpeg / ffprobe,
glslangValidator ($GLSLANG), android.jar API 34 ($ANDROID_JAR, napr. z github.com/Sable/android-platforms
android-34/android.jar - jen jako classpath pro javac).
Vse najednou: PRAC=... INC=... GLSLANG=... ANDROID_JAR=... bash vse.sh      (vystupy VYSTUP_* sem)

1) Logika karuselu (C++ bez GPU): test_karusel.cpp                          -> VYSTUP_test_karusel.txt
   g++ -std=c++17 -O2 -I../../app/src/main/cpp/menu -o test_karusel test_karusel.cpp && ./test_karusel
2) Snimky menu pres Mesa (PNG): menu_snimky VYSTUP W H [--tv] [--zamky] poz:t ... | --karty | --vykon S
   g++ -std=c++17 -O2 -I$INC -o menu_snimky menu_snimky.cpp -l:libEGL.so.1 -l:libGLESv2.so.2
   EGL_PLATFORM=surfaceless ./menu_snimky PRAC 1080 2340 0:3 1:3 ...        -> VYSTUP_menu_snimky.txt
   (--karty = obrazky karet bez textu pro zalozni HTML: assets/menu/karta_<id>.jpg)
3) SKUTECNY nap_menu_gl.cpp pres JNI jako z Javy: test_menu_host.cpp + tv_menu.cpp
   g++ -std=c++17 -O2 -pthread -I../b304/stub -I../b291/stub -I$INC -I$JAVA_HOME/include
       -I$JAVA_HOME/include/linux -I../../app/src/main/cpp/tvproud -o test_menu_host test_menu_host.cpp
       -l:libEGL.so.1 -l:libGLESv2.so.2                                      -> VYSTUP_test_menu_host.txt
