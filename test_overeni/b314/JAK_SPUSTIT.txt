B314 - JAZYK CZ / EN V CELE APPCE
=================================

Rene: "slo by dat vyber jazyka - volbu Cze a Ang? Myslim tim, ze by po volbe na ang byla apka
v anglictine? a naopak?"

Volba: OPTIONS -> JAZYK · LANGUAGE (CESTINA / ENGLISH). Dokud nikdo nevolil, plati jazyk telefonu
(cs / sk = cesky, jinak anglicky). Prepne se hned, i za chodu.

Kod v appce:
  NapJazyk.java                jazyk appky (SharedPreferences nap_jazyk, poprve podle telefonu),
                               NapJazyk.t(c, "cesky", "English")
  MainActivity.java            most AHJAZYK (kod, nastav), tx() u dialogu a hlasek, jazykDoKnihoven
                               (menu, intro, Atari pri zapnuti), karta HELP anglicky -> napoveda/en.html,
                               stranka WEB TV anglicky (napTvJazykStranka: prekladac + slovnik za </title>,
                               napoveda klavesnice pres napTr), anglicka napoveda Atari (ATARI_HELP_EN)
  NapPravidla.java             duvodZamku / duvodKarty cesky / anglicky, cilPodleJazyka (HELP)
  NapStahovaniSeSouhlasem.java, NapAktualizace.java   dialogy stahovani a aktualizace anglicky
  NativeMenuBridge.java        menuJazyk (24. native metoda), NativeIntroBridge.java introJazyk
  assets/spolecne/nap_jazyk.js prekladac stranek (ES5): slovniky assets/jazyk/en_*.js, vzory, hlidani
                               zmen (MutationObserver), alert / confirm / prompt, canvas, data-cs-only /
                               data-en-only, data-en-src (obrazek s textem), prepnuti za chodu
  assets/jazyk/en_menu.js, en_atari.js, en_konzole.js, en_sega.js, en_ps1.js, en_mp3.js, en_tv.js
  assets/index.html            prepinac JAZYK · LANGUAGE, zalozni karusel z anglickych sloupcu karty.txt,
                               zamky, obrazek karty HELP anglicky (karta_help_en.jpg)
  assets/napoveda/en.html      anglicky navod (stejne kapitoly jako index.html, nazvy tlacitek anglicky);
                               index.html <-> en.html se presmeruji podle AHJAZYK.kod()
  assets/menu/karty.txt        sloupce 11-14 anglicky (NAME | subtitle | description | button)
  assets/emu_sega/sega_megadrive_screen_en.png   obrazek konzole s anglickymi napisy (sega_skin_en.py)
  cpp/menu/nap_menu_karty.h    Karta.cz[4] / en[4], pouzijJazyk; nap_menu_gl.cpp menuJazyk;
                               nap_menu_kresba.h napisy LOCKED / hint na TV; nap_menu_umeni_help.h kniha
                               GUIDE / CONTROLS
  cpp/intro/nap_demo.h         titulky jen anglicky, zaverecne titulky anglicky; nap_intro_gl.cpp introJazyk
  cpp/atari/nap_atari_jazyk.h  tx(), stitek(), chybaKazety(), radkuText(); nap_atari_device.h /
                               nap_atari_runtime.h / nap_atari_native.cpp hlasky a stitky,
                               devCtl "jazyk:en|cs" -> Device::jazykZmenen (na sirku znovu predkreslit
                               tlacitka - stitek MEZERA / SPACE)

Spoustet z adresare test_overeni/b314 (nebo odkudkoli: bash test_overeni/b314/vse.sh).
Potreba: g++, JAVA_HOME = JDK, hlavicky EGL / GLES2 / KHR + stb_image_write.h v $INC (jako ../b311),
knihovny Mesa (libEGL, libGLESv2), zlib, Python 3 + numpy + Pillow + wordfreq (ceska slova bez
diakritiky), Chromium + Playwright pro Python, Node.js (acorn se doinstaluje do PRAC), android.jar
API 34 ($ANDROID_JAR), glslangValidator ($GLSLANG) a ffmpeg / ffprobe pro regresi.
Vse najednou: PRAC=... INC=... GLSLANG=... ANDROID_JAR=... bash vse.sh        (vystupy VYSTUP_* sem)
