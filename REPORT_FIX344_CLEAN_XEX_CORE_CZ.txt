KODY JSOU ZMENENE.

Tohle NENI rollback.
Tohle je dopredny cisty overlay s jednim aktualnim UI vstupem a jednim aktualnim TBXL/XEX panelem.

Zachovano:
- POWER XL/XE BASIC jako zakladni realny Atari BASIC start.
- BASIC TXT/BAS pomocnik jako servisni vkladani po READY, ne fake boot.
- Mobilni Atari klavesnice.
- Warm reset logika jadra zustava v emulacnim jadru.
- Turbo Basic XL 1.5 XEX soubor zustava v assets.

Opraveno proti rozbitemu vrstveni:
- index.html je cisty aktualni vstup.
- emu overlay ukazuje jednu aktualni hlavicku a jeden aktualni panel.
- pridana ochrana, ktera cisti pripadne stare textove hlasky z logu/statusu, aby se v UI neobjevovaly stare build labely.
- stary viditelny bordel panelu se nema zobrazovat ani po 15 sekundach.

TBXL/XEX:
- TBXL startuje pres direct XEX parser do emulovane RAM.
- Log musi ukazat, jestli STREAMED/ACTIVE, MEM_6132 a MEM_0B00 opravdu sedi.
- Vstup klaves jde pres aktualni frontu a OS latch: CH $02FC, ATACHR $02FB, KBCODE $D209, SKSTAT $D20F.

- Nemam tvoje Android/Nox prostredi, takze netvrdim 100% ze TBXL uz prijima prikazy.
- Tenhle ZIP je ale pripraveny tak, aby nejdriv zastavil UI bordel a dal jeden cisty log pro dalsi krok.
